## 新增活動

## 嫩豆腐接接樂 上線前待辦

- 活動期間 2026/11/16–11/30（`EVENT_START`／`EVENT_END`），期間外只能試玩、不發券；網址加 `?test=1` 可在期間外測試發券。
- 1800 分以上發 9 折固定折扣碼 `8FNSP`（findpos 店號 3818），券面附 QR code。
- 錄製的語音檔填進 `VOICE_CLIPS`。
- 目前優惠券紀錄只存在玩家手機，正式上線建議接後端資料庫記錄發券與核銷。
